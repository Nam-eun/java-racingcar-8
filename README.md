# 자동차 경주 게임

## 프로젝트 개요

사용자가 입력한 자동차 이름들을 바탕으로 경주를 진행하는 프로그램입니다.  
각 자동차는 랜덤한 조건에 따라 전진하며, 모든 라운드가 끝난 후 **라운드별 결과**와 **최종 우승자**를 출력합니다.

---

## 기능 요구사항

### 1. 입력을 받아서 처리한다

- 사용자에게 자동차 이름을 입력받는다.
    - 이름은 쉼표(,)로 구분한다.
    - 예: `pobi,crong,honux`
- 시도할 횟수(라운드 수)를 입력받는다.
    - 예: `5`

### 2. 자동차 경주를 구현한다

- 각 자동차는 한 라운드마다 0~9 사이의 랜덤 숫자를 생성한다.
- 생성된 숫자가 **4 이상**이면 전진(`-` 추가)
- 모든 자동차는 매 라운드마다 독립적으로 움직인다.

### 3. 매 라운드 결과와 우승자 목록을 출력한다

- 각 라운드 종료 후 자동차별 진행 상황을 출력한다.
